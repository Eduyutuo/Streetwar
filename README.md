# RITMO Streetwear

Sitio editorial multipágina de moda urbana inspirado en la estructura de una tienda contemporánea, con identidad, fotografías y contenido originales.

## Páginas

- Inicio
- Novedades
- Hombre
- Mujer
- Niños
- Marcas
- Ofertas
- Lanzamientos
- Editorial
- Tiendas

El contenido estático listo para publicar se encuentra en `dist/`. GitHub Actions despliega automáticamente esa carpeta en GitHub Pages con cada cambio en `main`.
